# 0015 貯金・投資に移したお金は、支出に数えず別に出す

- 日付：2026-11-28
- 背景：NISA の積立（毎月4,000円）を支出として記録すると、純資産は減っていないのに、支出が増え、予算の残りと毎月の余りが減って見える。資産のタブでは同じ4,000円を「入れた額」として数えるので、家計簿と資産で食い違う
- 決定：
  - 支出のカテゴリに「貯金・投資」の印（`categories.saving`）を付けられるようにする。親に付いていれば子も同じ
  - 印の付いたカテゴリの記録は、支出（expense）・カテゴリ別・予算に数えず、貯金・投資（saving）として別に出す
  - 収支は「収入 − 支出」とし、貯金・投資に回した分を含む余りにする。貯金・投資に回したあとに残る額は別に出す
  - 初期カテゴリに「貯金・投資」（キーワード：積立・NISA・iDeCo・貯金・投資）を足す。今のユーザーには移行 SQL で足し、同じ名前のカテゴリがあれば印を付ける
  - 記録のしかたは今までどおり（LINE で「NISA 4000」、固定費の自動記録）。新しい種類（振替）は作らない
- 理由：
  - 記録の種類（支出・収入）に振替を足すと、LINE の解析・画面・集計のすべてに手が入る。カテゴリの印なら、集計（`monthSummary`・`trend`）を直すだけで、ホーム・予算・AI が同じ数字を使える
  - 収支を「収入 − 支出」にしておくと、AI が「毎月いくら回せるか」を考えるときに、すでに回している分を使ったお金と取り違えない
- 代替案：
  - 積立は家計簿に記録せず、資産のタブの「入れた額」だけで持つ：作りは変わらないが、家計簿だけ見ると積立がどこにも出ない（ユーザーが選ばなかった）
  - 記録の種類に「振替」を足す：口座間の移動も表せるが、手を入れる所が多い
