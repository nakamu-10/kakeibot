# 0013 固定費は、固定費ごとに選んで、払う日に家計簿へ自動で記録する

- 日付：2026-11-28
- 背景：固定費・サブスクを登録できるようにした（Issue #18 段階2）。はじめは登録するだけで、家計簿には記録しないことにしていた。口座から引き落とされたものを手でも記録すると二重になるため。しかし家計簿に入っていないと、支出の合計や予算の残りが実際より少なく見える
- 決定：
  - 固定費ごとに「自動で記録する」を選ぶ（既定はオン）。オンのものは、払う日の朝8時（給料日と同じ Cron）に支出として記録する。source は 'fixed'
  - 二重は、オンにしたものは手で記録しない、とユーザーに決めてもらうことで防ぐ。アプリでは重なりを調べない
  - 払う日が月末より後なら月末に記録する。毎年のものは払う月だけ。同じ日に2回は記録しない（last_recorded）
  - 仕送りと同じく、記録だけして通知しない。記録忘れ通知の判定には数えない
- 理由：
  - 引き落としの日と金額は決まっているので、自動で記録すれば手間がなく、漏れもない
  - 似た記録を探して飛ばす方法は、金額や日がずれたときに外れ、どちらが記録されたか分かりにくい。ユーザーがこの方法を選ばなかった
- 代替案：
  - 似た記録があれば飛ばす（日の前後3日・同じカテゴリ・ほぼ同じ金額）
  - 必ず記録して LINE で知らせ、重なったら消してもらう
