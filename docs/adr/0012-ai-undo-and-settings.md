# 0012 AI に予算などの設定も変えさせ、その代わりに変更を1回の依頼ごとに取り消せるようにする

- 日付：2026-11-28
- 背景：AI を資産運用の相談役にしたい（Issue #18）。そのために予算・固定費・目標・口座・残高を AI と話しながら決めたい。0010 では「設定は AI に変えさせない、提案まで」としていた
- 決定：
  - AI から、予算・固定費・目標・口座・残高を登録・変更してよい（段階ごとに足す）。カテゴリとシフト収入の設定は今までどおり変えさせない
  - その代わり、AI が家計簿に加えた変更を `changes` に残す。1回の依頼（ツールの1回の呼び出し）を batch とし、変える前・後・要約を持つ
  - 取り消しは batch の単位。後ろから戻し、その後に人が直したもの（今が「変えたあと」と違うもの）は戻さずに知らせる。消した記録は同じ id で戻す
  - 取り消しは MCP（`undo_changes`）と家計簿の画面（設定の「AI による変更」）の両方からできる。取り消し自体は履歴に残さない（もう一度やり直す機能は作らない）
  - 履歴に残すのは AI からの変更だけ。LINE や家計簿の画面からの変更は残さない
- 理由：
  - 取り消せれば、AI に任せる範囲を広げても、間違えたときにすぐ戻せる
  - 人があとで直したものまで戻すと、人の直しを消してしまう。今の値が「AI が変えたあと」と同じときだけ戻せば安全
  - LINE や画面での変更は、その場で人が見ているので、取り消しの必要が小さい
- 代替案：
  - 記録ごとに版を全部残す（イベントソーシング）：どの時点にも戻せるが、表と処理が大きくなる
  - 取り消しの取り消し（やり直し）：今は要らない。必要になったら、取り消しも batch として残せば作れる
- 0010 の「設定は AI に変えさせない」は、この ADR で変えた
