# 0007 記録忘れ通知は、オンにした人へ毎晩21時に送る

- 日付：2026-11-28
- 背景：記録しない日が続くと、家計簿が続かなくなる。夜に一言知らせたい
- 決定：
  - Cron Trigger で毎晩21時（日本時間。`0 12 * * *` UTC）に動かす
  - 通知をオンにしていて、その日（日本時間0時以降）に自分で1件も記録していない人に送る。記録の日付ではなく、記録した時刻（`created_at`）で見る。給料日の自動記録は数えない
  - 最初はオフ。トークの「通知オン」「通知オフ」か、家計簿の設定画面で切り替える
  - 対象の人は SQL 1本で選ぶ（CPU 時間と D1 の読み取りを抑える）
- 理由：
  - 寝る前なら、その日の分を思い出して記録できる
  - LINE の無料プランはプッシュが月200通で、友だち全員の合計。毎晩送ると1人で月最大30通を使うので、欲しい人だけにする
  - 昨日の分を今日記録した日も「使った日」なので、時刻で見る
- 代替案：
  - 時刻を人ごとに選べるようにする：Cron を1時間ごとに動かす必要があり、今は要らない
  - 何日か続けて記録がないときだけ送る：毎日記録する習慣づけには、その日のうちに知らせる方がよい
