# 0008 カテゴリを親と子の2段にする

- 日付：2026-11-28
- 背景：「日用品」の中を「服」「雑貨」のように細かく分けて見たい。カテゴリを増やすだけだと一覧とグラフが長くなり、「日用品の合計」も出せない
- 決定：
  - `categories.parent_id`（0 = 一番上の段）で親子にする。2段まで。親は同じ種類（支出・収入）の一番上のカテゴリだけ
  - 記録（`entries.category`）は今までどおりカテゴリ名を1つ持つ。子の名前も、ほかのカテゴリと重ならない
  - 集計は親でまとめ、子の内訳を添える。親そのものに付けた記録は内訳に「（親名）」として出す
  - トークでは「服 3000」も「日用品 服 3000」も子に記録する。キーワードが同じ長さなら子を優先する
  - 親を消すと、子は一番上の段に上がる。記録は残す
  - 親でまとめる計算はサーバー（`src/category.ts`）に置き、LIFF にはまとめた結果を返す
- 理由：
  - 記録の形を変えないので、今の記録・CSV・レシート読み取り・シフト収入の自動記録がそのまま動く
  - 3段以上は家計簿には細かすぎ、画面も集計も複雑になる
- 代替案：
  - 記録に親と子の2つの列を持たせる：記録の形が変わり、今の記録の移行と、カテゴリ名を変えたときの付け替えが増える
  - タグ（複数付けられるラベル）：集計が重なり、合計が支出と合わなくなる
