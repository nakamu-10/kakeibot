# 0006 給料日・仕送りの日に見込み額を家計簿へ記録する

- 日付：2026-11-28
- 背景：シフト収入で給料日と見込み額は分かるようになったが、家計簿の収入は自分で記録する必要があった。給料日のたびに同じ金額を打ち込むのは手間
- 決定：
  - 毎朝の Cron（給料日の通知と同じ実行）で、その日の給与を「給与」、仕送りを「仕送り」の収入として記録する。メモは「珈琲館 10/1〜10/31分」のようにする
  - 記録したことを `payday_entries`（ユーザー・給与か仕送りか・バイト先か仕送りの id・日付）に残し、同じものを二度記録しない。手で消したあとも記録し直さず、直した金額も上書きしない
  - 給料日の通知に「金額を直す」を付ける。押すと、その記録を `users.fix_entry_id` に10分だけ覚え、次に数字だけ送られたら金額を直す。ほかの入力が来たら待つのをやめる
  - 仕送りは記録だけして通知しない（0004 と同じ理由）
  - シフト収入の設定に、自動で記録するかどうか（`shift_settings.auto_record`、初期値はオン）を置く
  - 初期カテゴリに「仕送り」を足し、「お小遣い」のキーワードから「仕送り」を外す。今使っている人には、初めて仕送りを記録するときに「仕送り」カテゴリを作る
- 理由：
  - 見込み額で先に記録しておけば、ずれたときだけ直せばよい
  - 記録の印を別のテーブルに置くと、家計簿の記録を消したり直したりしても、自動の記録がそれを上書きしない
  - 金額を直すのは数字を送るだけにしたい。LINE には数値を入れる部品がないので、押した記録を短い時間だけ覚えておく
- 代替案：
  - 実際の入金額を銀行から取り込む：口座との連携が要り、個人の家計簿には重い
  - 「直す 6500」のようなコマンドで直す：どの記録を直すか分からなくなる（同じ日に給与が2つあるときなど）
- 注意：今使っている人の「お小遣い」カテゴリには「仕送り」のキーワードが残るので、トークで「仕送り 50000」と送ると「仕送り」でなく「お小遣い」になる。気になる場合は、設定画面でキーワードを直す
