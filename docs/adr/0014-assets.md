# 0014 資産は、口座ごとに月に1回の残高を入れて持つ

- 日付：2026-11-28
- 背景：AI に資産運用の相談に乗ってもらうため（Issue #18 段階4）、資産の分け方と推移を正確な数字で渡したい
- 決定：
  - 口座ごとに、月に1回の残高を入れる（画面か AI に伝える）。証券会社や銀行とはつながない
  - 口座の種類は、預金・現金、NISA、iDeCo、証券（課税）、暗号資産、その他の資産、借金。借金も入れ、純資産（資産 − 借金）を出す
  - 投資の口座（NISA・iDeCo・証券・暗号資産）では、その月に入れた額（積立など）も入れる。増えた分を「入れた額」と「値動き」に分けて振り返れるようにする。省いたら前の月と同じ額にする
  - その月に入れていない口座は、前の月の残高のままとして数える
  - 口座を消すと残高もすべて消えるので、AI からは消させない。AI は解約（active を false）まで。消すのは画面から
  - 銘柄や商品をアプリから勧めない。アプリは数字を渡すところまでにし、考え方の整理は AI アプリに任せる
- 理由：
  - 口座とつなぐ（スクレイピングや API）は、認証情報を預かることになり、公開リポジトリの個人開発では危ない。月1回の手入れなら手間も小さい
  - 借金を入れないと、奨学金の返済と貯金・投資のどちらを優先するかを相談できない
  - 入れた額がないと、資産が増えたのが積立のおかげか値上がりのおかげか分からない
- 代替案：
  - 残高だけを入れる：手間は少ないが、積立と値動きを分けられない
  - 銘柄ごとに持つ：資産の分け方をもっと細かく見られるが、毎月の入力が重くなる
