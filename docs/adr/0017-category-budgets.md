# ADR 0017: カテゴリ別予算

日付：2026-11-28
状態：提案

## 背景

今の予算は `users.budget` に1つだけ（月の全体予算）。「食費を3万に抑えたい」「交際費が膨らみがち」のようにカテゴリ単位で管理したいことがある。全体予算だけだと、どのカテゴリが予算を食っているかが分かりにくい。

カテゴリ別予算があれば、次の段階（Lv6 通知：予算8割の警告）で「食費が予算の8割を超えました」のようなカテゴリ単位の警告も出せる。

## 決めたこと

### 粒度は親カテゴリ単位

- 親カテゴリ（`parent_id = 0` のもの）ごとに予算を設定できる
- 子カテゴリ個別には設定しない（細かすぎる。子の支出は親にまとまる）
- 貯金・投資のカテゴリ（`saving = 1`）には予算を設定しない（使ったお金ではないので）
- 収入カテゴリにも設定しない

### 全体予算との関係

- 全体予算（`users.budget`）はそのまま残す。カテゴリ別予算とは独立
- カテゴリ別予算の合計が全体予算と一致する必要はない
  - 全部のカテゴリに予算を付けるとは限らない
  - 「食費だけ管理したい」というのもありえる

### DB

`category_budgets` テーブルを足す。

```sql
CREATE TABLE IF NOT EXISTS category_budgets (
  user_id      TEXT NOT NULL,
  category_name TEXT NOT NULL,  -- 親カテゴリの名前（categories.name）
  amount       INTEGER NOT NULL,  -- 月の予算（円）。0 で予算なし（行ごと消す）
  PRIMARY KEY (user_id, category_name)
);
```

カテゴリの名前を変えたら、`category_budgets` のキーも付け替える（`updateCategory` で既に entries の付け替えをしているので、同じところに足す）。カテゴリを消したら、その予算も消す。

### LINE トーク

- `予算 食費 30000` → 食費の月予算を ¥30,000 に設定
- `予算 食費 0` または `予算 食費 なし` → 食費の予算を消す
- `予算 50000` → 今と同じ（全体予算）
- `予算` → 全体予算と、設定済みのカテゴリ別予算を表示

### 記録後の返信

支出を記録したあとの返信に、そのカテゴリに予算があれば表示する。

```
記録しました ✓
[食費] ランチ ¥800

今月の食費 ¥18,000 / ¥30,000（60%）
今月の支出 ¥45,000
予算残り ¥5,000
```

### 月のまとめ（`今月` / `先月`）

カテゴリ別のところに、予算があるカテゴリだけ残額を出す。

```
― カテゴリ別 ―
食費 ¥18,000 / ¥30,000
  外食 ¥12,000
  自炊 ¥6,000
交通費 ¥5,000
日用品 ¥3,000
```

### LIFF 画面（`/api/summary`）

`/api/summary` のレスポンスに `categoryBudgets` を足す。画面側でカテゴリ別の横にプログレスバーなどを出す（画面の変更は別 PR でもよい）。

`PUT /api/budget` を拡張するか、`PUT /api/category-budgets` を足す。

### MCP

- `get_summary` のレスポンスに、カテゴリごとの予算を足す（`expenseByCategory` の各項目に `budget` フィールド）
- `get_budget_status` を拡張して、カテゴリ別の予算ペースも返す
- `set_budget` を拡張して、`category`（省略可）を受け取れるようにする。指定すればカテゴリ別、なければ全体
- 変更の履歴と取り消しの対象に `category_budget` を足す

### `financialOverview`（相談のまとめ）

`spendingByCategory` にカテゴリ別予算を足して、AI が「食費は予算内で収まっています」「交際費は予算がありません」のように答えられるようにする。

## やらないこと（今回は）

- 子カテゴリへの予算設定
- 月ごとに予算を変える（12月は交際費を多めに、など）→ 要望があれば後で
- カテゴリ別予算の合計が全体予算を超えたときの警告
- 予算8割の通知（Lv6。この ADR の次のステップ）
