# 0009 LIFF 画面を、LINE になじむ大きく柔らかい見た目にする

- 日付：2026-11-28
- 背景：LIFF 画面は「入力しにくく、見た目が AI が作った画面らしい」と感じられていた。架空のデータでスマホの幅のスクリーンショットを撮って見直すと、次のことが分かった
  - 入力欄の文字が 15px で、iPhone が入力のたびに画面を拡大する
  - 記録の追加が「履歴」タブにしかなく、金額が最初でない
  - カテゴリの編集がブラウザの入力窓を3回続けて出す形
  - ボタンが小さく、押し間違えやすい
  - 保存のたびにブラウザの確認窓が出る
  - 配色（生成りの背景・テラコッタ・深緑）と、灰色の小見出しと細い線だけの繰り返しが「ありがちな AI の画面」に見える
- 決定：
  - 白いカード・LINE に近い緑・大きめの文字とボタン・角の丸い柔らかい見た目にする（0001 の頃の「落ち着いた表中心、角丸カードを多用しない」から変える）
  - 入力欄は 16px 以上、押せるものは高さ 44px 以上
  - 記録はどのタブからも「＋ 記録する」で、下から出る入力欄で付ける（金額が先頭、カテゴリはよく使う順のボタン、日付は今日・昨日・日付選択）
  - ブラウザの `alert`・`confirm`・`prompt` は使わない。知らせは短く出て消える表示、削除は2回押す
  - カテゴリ別は、支出全体を100%にした帯と、カテゴリごとの割合・金額の一覧（ドーナツグラフをやめる）
  - 共通の見た目は `src/ui.css` にまとめ、2つの画面で使う
  - 画面の確認のために `scripts/preview.mjs`（架空のデータで LIFF 画面を開く）を置く
- 理由：
  - 問題は部品が足りないことではなく、入力の流れと見た目の方針にあったので、素の HTML のまま直せる
  - LINE の中で開く画面なので、LINE に近い見た目の方が違和感がない
- 代替案：
  - Astryx（Meta の React のデザインシステム）で作り直す：部品はそろうが、React とビルドが要り、2つの画面を書き直すことになる。まだ Beta で、読み込みも重くなる
  - 紙の家計簿ノート風（罫線の表・インクの青と赤）：表中心の方針には合うが、柔らかい見た目にしたいという希望に合わない
