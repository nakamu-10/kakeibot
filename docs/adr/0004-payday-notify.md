# 0004 給料日の通知は毎朝8時に、給料日のバイト先がある人だけへ送る

- 日付：2026-11-27
- 背景：シフト収入の給料日に、見込み額をトークで知らせたい。LINE のプッシュは無料プランだと月に送れる通数に上限があり、Workers も CPU 時間と fetch の回数に上限がある
- 決定：
  - Cron Trigger で毎朝8時（日本時間。`0 23 * * *` UTC）に動かす
  - まず D1 の設定だけで「今日が給料日のバイト先があるか」を調べ、ある人だけカレンダーを読んでレポートを作る
  - 送るのは、その日に支給される給与（バイト先ごと）だけ。仕送りは送らない
  - 1人の失敗（カレンダーが読めないなど）で、ほかの人への通知を止めない
  - トークの「収入」「入金予定」で今月の入金予定を返す。「収入 バイト 30000」は今までどおり収入の記録
- 理由：
  - 朝なら、その日のうちに入金を確かめられる
  - 給料日は月に数回なので、全員のカレンダーを毎朝読むより、設定で先に絞る方が CPU 時間・fetch・通数のどれも少なく済む
  - 仕送りは金額も日付も決まっていて、知らせる意味が薄い。通数も節約できる
- 代替案：
  - 給料日の前日に知らせる：入金の確認には当日の方が合う
  - 通知のオン・オフ設定を作る：今は使う人が少ないので作らない。要望があれば shift_settings に列を足す
- 注意：Cron の1回の実行でも CPU 時間の上限がある。給料日の人が多い日は、1回の実行で全員分を作りきれないことがある。人数が増えたら、Queues で1人ずつに分ける
