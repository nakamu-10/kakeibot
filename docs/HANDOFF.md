## 作業のこつ

- LIFF の画面を変えたら、`node scripts/preview.mjs`（架空のデータ、ポート 8790）で開き、スマホの幅（390px）で撮って見比べる
  - Edge を `--window-size` だけで撮ると、幅が 500px より狭くならない。DevTools Protocol で端末をまねる
  - プレビューは node から拡張子なしの import を読めないので、`src/goals.ts`・`src/assets.ts` などは読まず、`scripts/preview.mjs` に簡単な代わりの計算を置いている
- MCP のツールは、ローカル D1（`getPlatformProxy`）と、SDK の `InMemoryTransport` で MCP クライアントから呼んで確かめる。HTTP 経由だと Node が Host ヘッダーを落とすので通らない
- MCP の認可（`/authorize` など）は、`npm run dev:mcp`（ポート 8791）に curl で DCR の登録と `/authorize` を送って確かめる。`--var EXTRA_REDIRECT_URIS:...` で戻り先を足せる
- 本番の MCP でつながらないときは、`npx wrangler tail -c mcp/wrangler.toml --format json` をバックグラウンドで動かし（読むだけ）、`callback:` のログを見る。つながるまで数秒かかるので、先に curl を1回送って確かめる
- AI アプリがつながらなくなったら、コネクタを削除して追加し直す。Gemini は接続の解除だけだと、古い登録を使い回して許可のあとに止まった
- `node_modules` の一部が pnpm の形になっていて、手元に `pnpm-lock.yaml` がある（ユーザーのもの。commit しない）。`@modelcontextprotocol/client` は `node_modules/.pnpm/...` からでないと読めない
- 既にあるテストのファイルに足すときは、上書きしない（`cat >` で `src/remind.test.ts` を一度消しかけた）
- PR のマージは、ユーザーが「マージしていい」と言ったときだけ。レビューを省いたら、省いた手順と理由を PR にコメントしてからマージする
